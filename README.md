# Любимчик — сайт зоомагазина

Готовая адаптивная сборка лендинга для зоомагазина «Любимчик».

Проект уже подготовлен для деплоя на **GitHub Pages** в репозиторий с названием:

```text
lyubimchik
```

После деплоя сайт будет открываться по адресу:

```text
https://ВАШ_НИК.github.io/lyubimchik/
```

## Стек

- Next.js
- TypeScript
- React-компоненты
- Tailwind CSS
- Адаптивная верстка под телефон, планшет и ПК
- GitHub Actions для автоматического деплоя на GitHub Pages

## Что внутри

- Hero-блок с оффером и CTA
- Адаптивное меню
- Плавная прокрутка по секциям
- Категории товаров
- Преимущества магазина
- Карточки популярных товаров
- Интерактивная корзина на странице
- Блок «О магазине»
- Отзывы покупателей
- Контакты и форма обратной связи с успешным состоянием
- Footer

## Локальный запуск

Установите зависимости:

```bash
npm install
```

Запустите сайт локально:

```bash
npm run dev
```

Откройте в браузере:

```text
http://localhost:3000
```

## Проверка статической сборки

```bash
npm run typecheck
npm run build
```

После `npm run build` Next.js создаст папку `out` — именно она публикуется на GitHub Pages.

Для локального предпросмотра папки `out` можно выполнить:

```bash
npm run preview
```

## Как выложить на GitHub Pages

1. Создайте на GitHub новый репозиторий с точным названием `lyubimchik`.
2. Загрузите в него все файлы из этой папки проекта.
3. Зайдите в репозитории в `Settings` → `Pages`.
4. В поле `Source` выберите `GitHub Actions`.
5. Откройте вкладку `Actions` и дождитесь зеленой галочки у workflow `Deploy Lyubimchik to GitHub Pages`.
6. Откройте ссылку вида:

```text
https://ВАШ_НИК.github.io/lyubimchik/
```

## Важные файлы для GitHub Pages

- `next.config.ts` — включает `output: "export"`, `basePath: "/lyubimchik"` для GitHub Pages и статическую сборку.
- `.github/workflows/deploy.yml` — автоматически собирает сайт и публикует папку `out`.
- `public/.nojekyll` — помогает GitHub Pages корректно отдавать папку `_next` со скриптами и стилями.
- `.npmrc` — заставляет npm качать пакеты из публичного `https://registry.npmjs.org/`.

## Где менять данные

Основные тексты, категории, товары, отзывы и контакты находятся в файле:

```text
data/site.ts
```

## Примечание по форме

Форма обратной связи не отправляет данные на сервер. Она имитирует успешную отправку на клиенте и готова для подключения к API, CRM или почте.
