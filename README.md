# Любимчик — сайт зоомагазина

Современный адаптивный сайт «Любимчик».

Проект сделан как готовая frontend-сборка на Next.js, TypeScript и Tailwind CSS. Сайт можно запустить локально на компьютере.

## Что реализовано

В проекте есть основные блоки сайта:

- главный экран с оффером и кнопками;
- категории товаров;
- преимущества магазина;
- популярные товары;
- интерактивная корзина на стороне интерфейса;
- блок «О магазине»;
- отзывы покупателей;
- контактная форма;
- контактная информация;
- footer;
- адаптивное меню для мобильных устройств;
- плавная прокрутка по секциям;
- hover-эффекты для кнопок и карточек.

## Технологии

Проект собран на следующем стеке:

- Next.js
- TypeScript
- React
- Tailwind CSS
- GitHub Pages

```text
