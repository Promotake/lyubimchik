# Любимчик — сайт зоомагазина

Современный адаптивный сайт для зоомагазина «Любимчик».

Проект сделан как готовая frontend-сборка на Next.js, TypeScript и Tailwind CSS. Сайт можно запустить локально на компьютере или опубликовать через GitHub Pages.

## О проекте

«Любимчик» — это светлый, теплый и современный сайт для зоомагазина с уютной визуальной подачей, мягкими карточками, аккуратной типографикой и адаптацией под разные устройства.

Сайт подходит для презентации магазина, ассортимента, преимуществ, популярных товаров, отзывов покупателей и контактной информации.

## Что реализовано

В проекте есть основные блоки сайта:

- главный экран с оффером и кнопками;
- категории товаров;
- преимущества магазина;
- популярные товары;
- интерактивная корзина на стороне интерфейса;
- блок «О магазине»;
- отзывы покупателей;
- контактная форма;
- контактная информация;
- footer;
- адаптивное меню для мобильных устройств;
- плавная прокрутка по секциям;
- hover-эффекты для кнопок и карточек.

## Технологии

Проект собран на следующем стеке:

- Next.js
- TypeScript
- React
- Tailwind CSS
- GitHub Pages
