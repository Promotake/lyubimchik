# Любимчик — сайт зоомагазина

Современный адаптивный сайт «Любимчик».

Проект сделан как готовая frontend-сборка на Next.js, TypeScript и Tailwind CSS. Сайт можно запустить локально на компьютере.

## Что реализовано

В проекте есть основные блоки сайта:

- главный экран с оффером и кнопками;
- категории товаров;
- преимущества магазина;
- популярные товары;
- интерактивная корзина на стороне интерфейса;
- блок «О магазине»;
- отзывы покупателей;
- контактная форма;
- контактная информация;
- footer;
- адаптивное меню для мобильных устройств;
- плавная прокрутка по секциям;
- hover-эффекты для кнопок и карточек.

## Технологии

Проект собран на следующем стеке:

## Логотип

Логотип магазина лежит в папке:

```text
public/logo.png
```

Иконка для вкладки браузера лежит здесь:

```text
public/favicon.png
```

Сейчас логотип подключен в нескольких местах:

- верхнее меню сайта — `components/Header.tsx`;
- карточка в hero-блоке — `app/page.tsx`;
- footer — `app/page.tsx`.

Для замены логотипа достаточно заменить файл:

```text
public/logo.png
```

Лучше использовать PNG с прозрачным фоном. Рекомендуемый размер — от 512 px по ширине. Название файла оставьте таким же: `logo.png`.

Если нужно поменять путь или название файла, измените его в компоненте:

```text
components/Logo.tsx
```
